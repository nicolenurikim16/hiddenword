# 히든워드

내 단어는 숨기고 상대 단어는 맞히는 유사도 단어 게임입니다. 메인 페이지에서 방을 만들고, 초대 링크를 보내면 받은 사람이 가입 없이 바로 들어옵니다. 방은 여러 개가 동시에 따로 진행됩니다.

## 구성

- `server.js` : 서버. 방 관리, 게임 진행(심판), AI 유사도 채점을 맡습니다.
- `public/index.html` : 화면 전체.
- `package.json`, `render.yaml` : 배포 설정.

## 배포 (Render 기준)

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 전부 올립니다. `public` 폴더도 폴더째 올려야 합니다.
2. render.com 에 GitHub 계정으로 가입합니다.
3. New → Web Service → 방금 만든 저장소를 고릅니다.
4. 설정값: Build Command `npm install`, Start Command `npm start`, 플랜은 Free.
5. Environment Variables 에 `ANTHROPIC_API_KEY` 를 추가하고 값에 API 키를 넣습니다. 키는 코드나 저장소에 적지 마세요.
6. 배포가 끝나면 `https://...onrender.com` 주소가 나옵니다. 그 주소가 게임 사이트입니다.

## 사용

1. 사이트를 열고 "방 만들기"를 누릅니다.
2. 대기실의 "링크 복사"로 초대 링크를 복사해 카카오톡 등으로 보냅니다.
3. 2명 이상 참가하면 방장이 난이도를 고르고 "게임 시작"을 누릅니다.

## 알아 둘 점

- 무료 플랜은 15분 동안 아무 접속이 없으면 서버가 잠들고, 다시 깨어나는 데 1분쯤 걸립니다. 게임 중에는 화면이 서버에 주기적으로 신호를 보내 깨어 있게 합니다.
- 게임 상태는 서버 메모리에만 있습니다. 서버가 재시작되면 진행 중인 방이 사라집니다.
- AI 비용은 힌트 1개당 채점 1회, 연습봇의 힌트와 추리마다 1회씩 API 키로 과금됩니다. 사이트 주소를 아는 사람은 누구나 방을 만들 수 있으니, Anthropic 콘솔에서 월 사용 한도를 걸어 두세요.

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | 없음 | 필수. 유사도 채점용 키 |
| `MODEL` | `claude-sonnet-5-5` | 유사도 채점 모델 |
| `FAST_MODEL` | `claude-haiku-5-5` | 연습봇용 모델 |
| `MAX_ROOMS` | `30` | 동시에 열 수 있는 방 수 |
| `MOCK_AI` | 없음 | `1` 이면 키 없이 가짜 점수로 동작 (내 컴퓨터에서 화면만 볼 때) |

## 내 컴퓨터에서 실행

```
npm install
MOCK_AI=1 npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

## 유사도 계산 방식

AI가 힌트와 히든워드를 세 기준(의미적 거리, 문맥적 공생, 관계적 구조)으로 각각 0~100점 매기고, 서버가 정해진 공식으로 합칩니다. 가장 높은 기준에 0.45, 둘째에 0.35, 셋째에 0.2를 곱해 더한 뒤, 난이도에 따라 100과의 간격을 줄입니다(쉬움 0.5배, 보통 0.8배, 어려움 그대로). 수치는 `server.js` 의 `DIFF` 와 `combine` 에서 바꿀 수 있습니다.
